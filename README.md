# How Has the American Workweek Changed? (2000–2024)

## Project overview

This repository contains the R analysis for **Blog Post 3: How Has the American Workweek Changed?** It uses **IPUMS Current Population Survey (CPS) Basic Monthly microdata** to describe changes in actual weekly hours worked in the United States from January 2000 through December 2024.

**Research question:** How did actual weekly working hours change across age groups between 2000 and 2024, and how much of those changes appears in main jobs versus other jobs?

The analysis compares six age groups (16–24, 25–34, 35–44, 45–54, 55–64, and 65+) and produces five figures covering total hours, main-job hours, other-job hours, and the shares of hours attributable to main and other jobs. Results are descriptive; they do not identify causal effects.

> **Important — raw data are not included.** Neither `data/raw/cps_raw.csv` nor `data/raw/cps_raw.csv.gz` is distributed with this repository. To reproduce the analysis from the beginning, obtain your own IPUMS CPS extract using the instructions below. The R scripts do **not** download the data.

## 1. Obtain the raw data (required)

### Data source and scope

- **Provider:** [IPUMS CPS, University of Minnesota](https://cps.ipums.org/cps/). The underlying CPS is conducted by the U.S. Census Bureau and the U.S. Bureau of Labor Statistics.
- **Survey:** CPS **Basic Monthly**, not an ASEC-only extract.
- **Period:** January 2000–December 2024, inclusive (**300 monthly samples**).
- **Geography:** United States.
- **Access:** An IPUMS account and a locally downloaded extract are required. An API key is **not** needed to run the analysis after downloading the data.

### Create and download an IPUMS extract

1. Visit [IPUMS CPS](https://cps.ipums.org/cps/) and register or sign in.
2. Open the data-extract interface and select **all Basic Monthly samples from January 2000 through December 2024** (12 months per year, 25 years). Do not substitute annual ASEC-only samples.
3. Include **all of the following variables** in the extract:

   | Variable | Role in this project |
   |---|---|
   | `YEAR` | Survey year |
   | `MONTH` | Survey month |
   | `ASECFLAG` | Identify/audit ASEC versus Basic Monthly records |
   | `AGE` | Construct six age groups |
   | `EMPSTAT` | Identify respondents at work (`10`) |
   | `MULTJOB` | Identify single-job and multiple-job workers |
   | `WTFINL` | Person-level monthly analysis weight |
   | `AHRSWORKT` | Actual hours worked across all jobs in the previous week |
   | `AHRSWORK1` | Actual hours worked at the main job |
   | `AHRSWORK2` | Actual hours worked at other jobs |

4. Submit the extract request and download the resulting data as a **CSV** (or an archived/compressed CSV). Preserve the accompanying IPUMS extract description and codebook.
5. Extract/decompress the CSV, if needed, and place it at this **exact project-relative path**:

   ```text
   data/raw/cps_raw.csv
   ```

   Create `data/raw/` if it does not already exist. A file named `data/raw/cps_raw.csv.gz` may also be kept locally, but the analysis expects the **uncompressed** `cps_raw.csv`; the compressed file alone is insufficient.
6. Preserve the variables' **original numeric codes** and uppercase column names. Do not manually pre-filter, recode, or edit the raw input.

`ASECFLAG` must be included even if an initial variable check in the script does not list it: a later analysis step uses that column. An otherwise similar extract that omits `ASECFLAG` may fail.

## 3. Reproduce the analysis

With `data/raw/cps_raw.csv` in place, run the following commands **from the project root**, in order:

```r
source("code/01_clean_analyze.R")
source("code/02_make_figures.R")
```

**Step 1 — `code/01_clean_analyze.R`:** Reads the raw CPS CSV, audits the data, constructs the common working sample, calculates monthly and annual weighted estimates, and writes audit and sensitivity outputs to `data/processed/`. The cleaned person-level working sample is retained in R memory, not exported as a separate person-level CSV.

**Step 2 — `code/02_make_figures.R`:** Reads `data/processed/annual_age_hours.csv` **from disk** and exports the five PNG files to `figures/`. The figure script does not depend on objects still present in memory from Step 1 and can be run in a fresh R session once the annual file exists.

For a full reproduction, always run both steps starting from the downloaded raw CSV. Re-running the scripts may overwrite previously generated files with the same names.

## 4. Methods and cleaning decisions

The analysis focuses on people **aged 16 or older who were at work during the CPS reference week**, not the entire adult population. The documented baseline sample applies these rules:

- Keep `YEAR` from 2000 through 2024 and `MONTH` from 1 through 12.
- Keep `ASECFLAG = 2` or missing `ASECFLAG`, exclude `ASECFLAG = 1`, and flag unexpected nonmissing codes.
- Require finite `AGE` from 16 to below 999, `EMPSTAT = 10`, and positive finite `WTFINL`.
- Require valid values for all three cleaned actual-hours measures so that components are compared on a **common sample**.
- Keep `AHRSWORKT` when it is an integer from **1 to 198** and `AHRSWORK1` when it is from **0 to 99**.
- Set other-job hours to zero for confirmed single-job workers (`MULTJOB = 1`) when `AHRSWORK2` is `0` or `999`; for multiple-job workers (`MULTJOB = 2`), keep `AHRSWORK2` values from **0 to 99**. Other combinations yield missing cleaned other-job hours and are excluded from the common sample.
- Retain component value `99` as a topcoded observation, as in the original documented pipeline.

**Monthly estimates.** For each month and age group, actual hours are summarized by the person-weighted mean:

The script also reports sample counts, weighted population totals, weighted individual-level standard deviations, and the weighted percentage of people holding multiple jobs.

**Annual estimates.** Each annual mean is the **simple average of the twelve monthly weighted means** for an age group; months are equally weighted at this aggregation stage. Main-job and other-job shares are calculated as **100 × (annual mean component hours / annual mean total hours)**. They are **ratios of means**, not averages of individual shares. Confirmed single-job workers contribute zero other-job hours.

**Sensitivity analysis.** An additional specification excludes total hours above **168** or discrepancies between total and component hours greater than **1e-8**. The sensitivity outputs are diagnostic; all five published figures use the **baseline** `annual_age_hours.csv`.

## 6. Interpretation and limitations

- The sample includes people who **worked during the reference week**; it does not measure employment rates and excludes people not at work that week.
- Actual hours worked are not necessarily usual or contractual hours. Annual age-group averages conceal variation within the year and do not follow fixed individual cohorts.
- Reporting issues, topcoding, missing hours, and common-sample exclusions can affect results. Because the baseline retains some inconsistent components, main-job and other-job percentages do **not necessarily sum to exactly 100%**.
- CPS person-month records are not counts of unique individuals. The reported weighted individual standard deviations are **not** design-based standard errors; this workflow does not produce confidence intervals or significance tests.
- Results are **descriptive rather than causal**. The full original IPUMS extract provenance is unavailable, so exact numerical reproduction cannot be promised from a newly generated extract.
